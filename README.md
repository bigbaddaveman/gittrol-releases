# Gittrol releases

Download the latest Windows x64 installer from the [Releases page](https://github.com/bigbaddaveman/gittrol-releases/releases).

Gittrol is a Windows Git client. Git for Windows and the Microsoft Edge WebView2 Runtime are required. The installer includes the .NET runtime.

To check for updates, choose **Help > Check for updates** in Gittrol. The installer is not code-signed, so Windows may show a publisher or SmartScreen warning.
